# Changelog

All notable changes to this project are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/); versions follow SemVer.

## [0.1.1] - 2026-10-30

### Changed

- Comments: internal markers and internal note references removed (no behaviour change; the
  `sourceSha256` provenance header of the generated artefacts is untouched).

## [0.1.0] - 2026-10-19

### Added

- **`lib/host-adapter.mjs`** — the single source of `SVC` (ctx service names), `EV` (event names)
  and `HOST_ADAPTER_VERSION`; pure functions, zero dependencies, zero IO.
- **`lib/host-adapter.js`** — generated browser bundle (`window.__ModuleLoader__.load`), loader id
  equal to the package name.
- **`lib/host-adapter.d.ts`** — generated type declarations.
- **`lib/index.js`** — inert host half (`inject = []`, empty `apply`) whose only job is to put the
  package into the client boot graph.
- **`sync-client-host-adapter.mjs`** — idempotent generator with `--verify` / `--dry-run` /
  `--self-test`; artefacts carry a `sourceSha256` header.
- **`deploy.mjs`** — installs the package into `<DSH_HOME>/profiles/web`, backs up the three
  profile declaration files, appends the `cordis.patch.yml` `insert`, and runs three gates
  (escaping imports, artefact/source equality, syntax). Strict argument allow-list.
- **`lib/dsh-home.mjs`** — DSH home / web profile resolution (env-var first, same semantics as the
  previously published copy).
- **`lib/deploy-guard.mjs`** — shared deploy gates (argument allow-list, escaping-import scan,
  smoke import).
- `package.json` (scoped name, `dsh.client` declaration, `bin` entries), AGPL-3.0 + commercial
  dual licensing.

### Changed (relative to the private source tree)

- **Package name is now `@kira905/dsh-host-adapter-client`**, and the generator's `CLIENT_ID`,
  the bundle's `__ModuleLoader__.load({id})`, `exports.name`, `deploy.mjs`'s `PKG_NAME` /
  `PLUGIN_ID`, and the `cordis.patch.yml` insert id were all aligned to it.
- The generator resolves the workspace **relative to the repository root** (`ROOT = HERE`,
  source `lib/host-adapter.mjs`, targets `lib/host-adapter.js` / `.d.ts`) instead of assuming a
  private `tools/` tree layout.
- Dependency imports in `deploy.mjs` are now relative to the package root.
- Comments that named a specific machine were genericised.
- The product artefacts were **re-generated by the shipped generator itself** so the committed
  bundle is byte-identical to a fresh `planOf()` result.
